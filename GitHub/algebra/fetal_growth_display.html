📚 Linear Function Key Concepts

🔺 Slope (m)

Formula: m = (y₂ - y₁) ÷ (x₂ - x₁)

Meaning: Rate of change (rise over run)

Medical Context: How fast baby grows per week

📍 Y-Intercept (b)

Definition: Value when x = 0

Formula: Point (0, b) on the graph

Medical Context: Theoretical size at conception

📊 Domain & Range

Domain: Valid x-values (12-40 weeks)

Range: Valid y-values (20-400 mm)

Medical Context: Realistic pregnancy timeline

🏥 Medical Applications

Prediction: Estimate future growth

Comparison: Actual vs. expected size

Diagnosis: Identify potential issues
